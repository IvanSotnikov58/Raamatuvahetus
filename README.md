# Raamatuvahetus

#Arendusmudel
Scrum on Raamatuvahetuse rakenduse jaoks parim valik, kuna süsteem areneb järk-järgult ning funktsiooninõuded võivad õpilaste ja moderaatorite tagasiside põhjal muutuda. Scrum võimaldab lühikesi iteratsioone ja regulaarset uute funktsioonide, näiteks soovituste, teavituste, hinnangute ja modereerimise, lisamist. V-mudel on vähem sobiv, kuna see piirab funktsionaalsuse kiire muutmise võimalust.

Otsustasin kõigepealt ühte ekraani vaadata ja siis järgmise juurde liikuda, sest noh, ma ei tea, see on minu jaoks mugavam.
